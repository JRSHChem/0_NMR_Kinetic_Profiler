# 0_NMR_Kinetic_Profiler_
takes in 1H NMR fid files and outputs conc vs. time data by integrating a chosen signal against an internal standard.

User defined settings can be altered for each kinetic profile, and outputs a CSV file than can be used in following JRSHChem posts.

## Requirements
This requires that the data is already Fourier Transformed.
fid files be named in a systematic order.
